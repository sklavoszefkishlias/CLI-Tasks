CLI Tasks is simple cli task tracker application made in python.
It uses the .json format for storing the tasks in the tasks.json file.
$add "example task" to add a task
$list to print all the tasks and $list done/to-do/in-progress to print only the tasks with the parameter as the task status
$update 1 "exmaple text" to update the description of a given task
$mark done 3 to mark the status of a task
$delete 2 to delete a task
Prompts are case sensitive and mark statuses arent.
$exit to exit
